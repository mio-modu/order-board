## A. 대표 구축 사례 — kpopgo.app

해외 고객(외국인 K-pop 팬)을 대상으로 하는 영문 기반 다국어 정보 사이트.

| 항목 | 내용 | 확인 방법 |
|---|---|---|
| 총 페이지 | **236개** | sitemap.xml |
| 언어 | **11개** (영어 기준, 독일어·스페인어·프랑스어·일본어·중국어 번체·인도네시아어·포르투갈어(BR)·베트남어·태국어·필리핀어) | /de /es /fr /ja /zh-hant /id /pt-br /vi /th /fil |
| 구조화 데이터 | 전 가이드 페이지에 **HowTo + FAQPage + BreadcrumbList** 적용, dateModified 포함 | 페이지 소스 JSON-LD |
| 색인 요건 | robots.txt 전체 허용, sitemap 선언, **llms.txt·llms-full.txt 배포** | /robots.txt /llms.txt |
| 구축 기간 | **9일** (최초 발행 2026-10-14) | JSON-LD datePublished |

**동종 서비스의 일반 납기는 다국어 5개 이상 기준 40~45일**이다 (온라인 마켓 공개 패키지 기준).

### 성과 측정

구축 후 동일 질문 세트로 생성형 AI 노출을 측정하고 기준선을 기록했다.

```
영문 31문항 · 필리핀어/포르투갈어/태국어 각 20문항
측정 조건: 질문당 반복 질의 후 등장 빈도 평균
용도: 개선 작업 전후 비교
```

> 이 측정 체계를 서비스에 포함해, 구축 전후의 변화를 수치로 보고할 수 있다.
