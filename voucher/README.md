## 1. 두 개의 바우처, 어느 쪽인가

| | 수출바우처 | 혁신바우처 |
|---|---|---|
| 포털 | exportvoucher.com | mssmiv.com |
| 소관 | 중기부 / 산업부 | 중기부 |
| 모집 | **[상시모집]** ⚠️ | 수시 (월 단위 사이클) |
| 대상 서비스 | 해외 마케팅·디자인·**홈페이지 제작** | 제조 중소기업 혁신 |
| 우리에게 맞는가 | **맞다** | 제조업 중심이라 약함 |

**수출바우처가 1순위다.** 상시모집이고, 영문 홈페이지 제작이 실제 사용 항목이다.
혁신바우처는 2026년 공고가 전년 11월 3~18일이었으므로 **11월 초 공고를 지켜볼 것**. ⚠️

## 2. 자격 — 확인된 것

- 대한민국에 **사업자등록된 법인 또는 개인사업자** (개인사업자도 가능)
- 제외 대상
  - 국세·지방세 **체납** (법인 및 대표자 모두)
  - 휴·폐업
  - 최근 3년 내 정부지원사업 **제재 이력**
  - 부도·법정관리
  - **수요기업으로 참여 중인 기업 또는 특수관계 기업** (대표자가 같으면 특수관계)

### 지금 확인해야 할 것

- [ ] **루메인이 다른 바우처에 수요기업으로 들어가 있지 않은가.** 들어가 있으면 공급기업 등록이 막힌다
- [ ] 국세·지방세 체납 없는가 (증명서에 체납 기재되면 불인정)
- [ ] **대표자 개인 공동인증서 + 사업자 공동인증서** 둘 다 있는가 (혁신바우처는 둘 다 필수)
- [ ] ⚠️ **최근 3개년 표준재무제표증명**을 요구하는지. 2024년 공고 기준으로 요구했다.
      사업 연수가 짧으면 이 항목이 결격 사유가 될 수 있다 — **가장 먼저 확인할 것**

## 4. 탈락 사유 — 피해야 할 것

공개된 가이드가 공통으로 지적하는 반려 사유다.

1. **수출과 관련성이 없는 서비스** — 모든 서비스를 "해외 고객 확보"에 직접 연결해 서술해야 한다
2. **동일·유사 서비스의 복수 등록** — 비슷한 서비스를 여러 개 올리지 말 것. 하나로 묶는다
3. **정산 지침·표준 가격 가이드 미준수** — ⚠️ 포털에서 해당 분야 표준단가를 먼저 확인하고 그 범위에서 책정

> 참고: 수출바우처는 2026-10-16 **디자인개발분야 BI/CI개발 서비스 정산기준**을 개정 재안내했다.
> 분야별 정산기준이 수시로 바뀌므로 신청 직전에 다시 볼 것.

## 5. 등록할 서비스 설계

**하나로 묶어서 등록한다.** 유사 서비스 복수 등록은 반려 사유다.

### 주력: 영문·다국어 수출용 웹사이트 구축

| 항목 | 내용 |
|---|---|
| 서비스명 | 영문·다국어 수출용 웹사이트 구축 (구조화 데이터·기술 SEO 포함) |
| 수출 관련성 | 해외 바이어·소비자가 검색으로 기업을 찾고 문의하는 경로를 만든다 |
| 산출물 | 다국어 페이지, 문의 폼, 구조화 데이터, sitemap/robots, 검색엔진 등록 |
| 차별점 | **다국어 11개 언어 236페이지를 9일에 구축한 실적** |
| 단가 | ⚠️ 포털 표준단가 확인 후 그 범위에서 책정 |

### 부가 (가능하면 함께)

- 해외 바이어용 영문 콘텐츠 제작 (제품 설명·FAQ·가이드)
- **AI 검색 노출 진단** — 신규 항목이라 단독 등록이 어려울 수 있다.
  위 서비스의 **포함 산출물**로 넣는 편이 통과 가능성이 높다

## 6. 진행 순서

**1단계 — 오늘**
- [ ] exportvoucher.com 접속 → 공지사항에서 `[상시모집] 수행기관 모집` 공고 열기
- [ ] 공고문 PDF 받아서 **신청 자격 / 구비서류 / 서비스 분야 / 표준단가** 네 가지 확인
- [ ] 위 2번 체크리스트 네 개 확인 (특히 재무제표 연수)

**2단계 — 이번 주**
- [ ] 홈택스·위택스에서 증명서 3종 발급
- [ ] `service-plan.md`를 공고 양식에 맞춰 옮겨 적기
- [ ] `portfolio.md`의 실적을 증빙 가능한 형태로 정리 (계약서·납품확인서가 있으면 첨부)

**3단계 — 신청**
- [ ] 포털 회원가입 (사업자번호 일치 필수)
- [ ] 온라인 접수. **제출 후 수정 불가**이므로 제출 전 전체 재확인
- [ ] 심사 결과 대기 (혁신바우처는 월초 접수 → 3~4주차 평가 → 월말 선정)

## 7. 솔직한 기대치

- 공급기업 등록은 **영업이 아니라 자격 취득**이다. 등록됐다고 일이 바로 오지 않는다
- 수요기업이 **메뉴판에서 우리를 골라야** 매출이 생긴다. 등록 후에도 노출·실적이 필요하다
- 정산은 **제작 완료 후**다. 현금은 바로 안 들어온다
- **5주 안에 500만원이 나오는 경로가 아니다.** 11~12월에 자격을 만들어 2027년 사업에 올라타는 구조다

그럼에도 이 길을 택한 이유는 하나다.
**고객이 자기 돈을 내지 않으므로 설득이 필요 없다.** 예산은 이미 배정되어 있고,
수요기업은 메뉴판에서 고르기만 한다. 영업이 약한 쪽에게 가장 유리한 구조다.
